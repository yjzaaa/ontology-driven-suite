### 2.1 维度定义
- **知识形态**：原子思维方法、认知原理元概念、分析操作萃取、组合思维方法、场景应用、实体工具——复刻 wiki1 的三层（概念/场景/实体）并细分。
- **主题模块**：11 个 L1 主干，用于定位知识所属思维子域。
- **难度层级**：入门、进阶、高级，用于标注每个知识点的认知负荷（绿色/浅黄/深黄色块区分）。

### 2.2 矩阵解读
- **概念层 → 场景层**：原子思维方法（B01）与认知原理（B02）是底层「思维肌肉」，被组合方法（B04）与各类场景（B05–B07）反复调用。
- **组合方法是枢纽**：深度思考、系统思考、结构化思维、知识体系构建等把原子方法串成可复用的「方法包」，是 wiki1 从概念到场景的关键中转。
- **实体层是工具载体**：框架模型（SBR、MBSE、思维钻石）、知识库工具（Obsidian、AI知识库）、学习法（费曼、Anki）支撑方法的落地。
- **跨层依赖主线**：认知原理(B02) → 原子方法(B01) → 分析操作(B03) → 组合方法(B04) → 场景应用(B05–B07)，实体(B08–B11)贯穿提供工具/框架。
- **L3 覆盖统计**：总数 95 / 已覆盖 95 / 未覆盖 0 / 重复主归属 0。
- **颗粒度处理**：每个 L3 均拆解为 2–4 个 L4 原子（核心定义 / 操作步骤 / 典型工具 / 易错对比），矩阵以 L3 为统计口径，底层图谱展开 L4。
- **盲区标注**：wiki1 中未纳入本模型的其余 ~880 项原子概念/实体/场景，在底层图谱中作为「待扩展」方向，建议按本 L1–L4 框架继续回填。
