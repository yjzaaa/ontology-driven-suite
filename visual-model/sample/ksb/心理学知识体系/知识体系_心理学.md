# 心理学知识体系

> 本知识体系面向心理学通识学习，覆盖心理学导论与方法、生物神经基础、感觉知觉与注意、学习记忆与认知、发展心理学、人格与个体差异、社会心理学、异常与临床、健康咨询应用、认知神经与前沿。体系按 KSB v3.6 输出四类可视化文件。

## 建模前置分析

【领域】：心理学

【核心定义】：心理学是用科学方法研究心理过程、行为及其生物、社会和文化基础的学科。

【范围边界】：

- 包含：心理学研究方法、神经生物基础、认知过程、发展、人格、社会、异常临床、健康咨询、应用和前沿。
- 不包含：未经验证的心理测试、占星性格分析、个案诊断建议、治疗处方。
- 前置依赖：基础生物学、统计学、科学方法、伦理意识。

【目标受众与用途】：心理学入门学习者、教育/咨询/管理/产品/健康领域从业者、准备系统学习心理学的人。

【典型应用场景】：建立心理学通识框架；规划心理学课程学习路线；理解心理测量、行为改变、临床评估、组织教育和人机交互中的心理学基础。

【三层粒度规划】：顶层设10个主干；中间层采用「知识域 × 研究/应用活动 × 难度层级」三维矩阵；底层抽取 72 个 Atom 节点、76 条关系边；额外输出强制学习路线图。

## 知识抽取

### 概念

1. 心理过程：感知、注意、记忆、思维、情绪和动机等内部过程。
2. 行为：可观察和可测量的行动或反应。
3. 科学方法：通过观察、假设、测量和检验形成知识。
4. 神经元：神经系统信息传递的基本单位。
5. 注意：选择和调节信息加工资源的心理机制。
6. 学习：经验导致行为或心理表征发生相对持久变化。
7. 记忆：编码、储存和提取信息的过程。
8. 人格：个体稳定的情感、认知和行为模式。
9. 社会认知：人如何理解自己、他人和社会情境。
10. 心理障碍：心理功能、情绪或行为出现显著痛苦或损害的状态。

### 方法

- 实验法：通过操纵变量和控制条件检验因果关系。
- 相关研究：分析变量关系，但不能直接推出因果。
- 调查法：通过问卷或访谈收集自报告数据。
- 心理测量：用量表和测验评估心理构念，重视信度和效度。
- 临床评估：结合访谈、量表、观察和风险评估理解个案。
- 干预方法：包括CBT、行为改变、压力管理、危机干预等。

### 关系

心理学的知识网络从科学方法出发，连接生物神经基础和可观察行为；感觉、知觉、注意、学习、记忆构成认知过程主线；发展、人格和社会心理说明个体如何在生命周期与社会情境中形成差异；异常、临床、健康和咨询应用则将基础知识用于评估和干预。

## 一、顶层知识：领域主干

> 查看对应图表：[knowledge_top.html](knowledge_top.html)

### 1.1 心理学导论与方法

心理学以科学方法研究心理过程和行为。研究方法包括实验、相关、调查、观察和个案研究。学习这一部分要特别注意研究设计、测量、伦理和证据质量，因为它决定后续知识是否可靠。

### 1.2 生物与神经基础

心理活动离不开神经系统和身体状态。神经元、突触、神经递质、脑区、内分泌系统和睡眠共同构成心理活动的生物基础。该部分帮助学习者理解“心理不是脱离身体的抽象现象”。

### 1.3 感觉知觉与注意

感觉是刺激进入系统，知觉是大脑组织和解释刺激，注意决定哪些信息被优先加工。视觉、听觉、格式塔原则、深度知觉、选择性注意和执行控制是核心内容。

### 1.4 学习记忆与认知

学习解释经验如何改变行为，记忆解释信息如何被编码、储存和提取，认知解释人如何思考、解决问题和使用语言。经典条件作用、操作条件作用、观察学习、工作记忆、长时记忆是基础节点。

### 1.5 发展心理学

发展心理学研究人从婴儿到老年的变化。核心问题包括依恋、认知发展、社会化、身份认同、生命周期任务和发展研究方法。

### 1.6 人格与个体差异

人格心理学解释个体稳定差异。特质论、大五人格、精神分析、人本主义、动机、情绪调节和压力构成这一主干。

### 1.7 社会心理学

社会心理学研究个体如何受他人和社会情境影响。归因、态度、偏见、从众、服从、说服、群体决策和亲社会行为是核心主题。

### 1.8 异常与临床心理

异常心理关注心理障碍的表现、分类和成因，临床心理关注评估与干预。焦虑、抑郁、创伤、精神病性症状、临床访谈、心理量表和CBT是关键内容。

### 1.9 健康与咨询应用

心理学可用于健康行为改变、压力管理、危机干预、职业咨询、学习动机和组织管理。该部分强调将理论转化为可执行支持和干预。

### 1.10 认知神经与前沿

前沿方向包括脑成像、认知模型、机器学习心理学、人机交互、跨文化心理学和开放科学。它们推动心理学从单一行为研究走向多方法整合。

## 二、中间层知识：多维矩阵

> 查看对应图表：[knowledge_middle.html](knowledge_middle.html)

### 2.1 维度定义

- 知识域：方法基础、生物认知、发展个体、社会人格、临床健康、应用前沿。
- 研究/应用活动：观察、实验、测量、解释、干预、评估。
- 难度层级：入门、进阶、高级。

### 2.2 入门层解读

入门阶段重点是建立科学心理学的基本框架。应优先掌握心理学科学观、实验设计、相关与因果、神经元与脑区、感觉知觉机制、学习机制、儿童认知发展、人格特质、社会认知、心理障碍分类和CBT基础。

入门层的产出包括：概念卡片、实验设计模板、相关因果判断表、脑-行为映射表、学习机制对照表、发展里程碑表和障碍分类速查表。

### 2.3 进阶层解读

进阶阶段要理解测量、机制和应用边界。重点包括心理测量信效度、研究伦理、注意与执行控制、记忆系统、生命周期发展、情绪调节、社会影响、群体与关系、临床评估、健康行为改变。

进阶层的目标不是背诵理论，而是能判断一个研究结论是否可信，一个测验是否有效，一个干预是否有前提条件。

### 2.4 高级层解读

高级阶段关注复杂情境、临床风险和前沿方法。重点包括危机干预、脑成像与认知神经、开放科学与可重复性。高级学习者需要理解心理学证据的限制，知道何时需要专业转介，知道如何在文化差异和伦理要求下使用心理学知识。

## 三、最底层知识：知识网络

> 查看对应图表：[knowledge_bottom.html](knowledge_bottom.html)

### 3.1 核心节点群

底层图谱包含 72 个核心 Atom，覆盖方法、生物、认知、发展、人格、社会、临床、健康和前沿。关键枢纽包括科学方法、实验法、心理量表、神经元、选择性注意、工作记忆、生命周期发展、态度、压力、CBT和开放科学。

### 3.2 关联类型与网络特征

`depends` 表示学习前置，例如实验法依赖科学方法，工作记忆依赖注意，CBT依赖对焦虑和抑郁的理解。`contains` 表示组装关系，例如大五人格包含在特质论之下。`evolved` 表示理论或应用演进，例如操作条件作用发展到行为改变，研究伦理发展到开放科学。

### 3.3 学习路线总览

- 通识入门：科学方法 → 行为 → 神经元 → 感觉知觉 → 学习 → 记忆 → 发展 → 人格 → 社会 → 临床。
- 认知路线：神经元 → 感觉 → 注意 → 工作记忆 → 长时记忆 → 问题解决 → 认知模型。
- 发展人格路线：生命周期发展 → 依恋 → 认知发展 → 身份认同 → 特质论 → 大五人格 → 情绪调节。
- 社会路线：态度 → 归因 → 偏见 → 从众 → 服从 → 说服 → 群体决策。
- 临床健康路线：压力 → 焦虑/抑郁/创伤 → 临床访谈 → 心理量表 → CBT → 压力管理 → 危机干预。
- 前沿路线：科学方法 → 研究伦理 → 脑成像 → 认知模型 → 机器学习心理学 → 人机交互 → 开放科学。

## 四、学习路线图解读

### 4.1 通识入门路线

通识入门路线适合第一次系统学习心理学的人。它从科学方法和行为开始，再进入生物基础、感觉知觉、学习记忆、发展、人格、社会和临床。目标是建立心理学全景，不急于进入治疗或测评应用。

### 4.2 认知路线

认知路线适合关注注意、记忆、思维和人机交互的人。它从神经基础进入感觉知觉，再进入注意、工作记忆、长时记忆、问题解决和认知模型。该路线适合教育、产品、AI、人机交互方向。

### 4.3 发展人格路线

发展人格路线关注个体如何随时间变化以及个体差异如何形成。它从生命周期发展、依恋、认知发展、身份认同开始，再进入特质论、大五人格和情绪调节。

### 4.4 社会路线

社会路线关注人如何受社会情境影响。态度、归因、偏见、从众、服从、说服和群体决策构成主链条。该路线适合管理、传播、组织行为和公共议题理解。

### 4.5 临床健康路线

临床健康路线适合理解心理问题、健康行为和支持性干预。它从压力开始，连接焦虑、抑郁、创伤、临床访谈、心理量表、CBT、压力管理和危机干预。注意：该路线用于知识学习，不替代专业诊断和治疗。

### 4.6 前沿路线

前沿路线关注心理学研究如何与神经科学、计算模型、机器学习、人机交互和开放科学结合。它适合希望进入研究、数据分析、认知科学或产品研究的人。
