# 中国高中理科生知识体系

> 本知识体系按 `KSB_V3.5` 构建，面向中国普通高中理科方向学生。范围覆盖高考理科生的主干课程、跨学科能力、实验能力和考试策略；不把竞赛数学、大学先修课程或纯应试技巧作为主线展开。本文基于通用课程常识构建，未绑定某一省份新高考选科细则，建议结合当地教材版本和考试说明复核。

## 领域界定

【领域】：中国高中理科生知识体系  
【核心定义】：中国高中理科生知识体系，是以数学、物理、化学、生物为核心，以语文、英语和通用学习能力为支撑，服务于高中阶段理解科学问题、完成课程学习和应对升学考试的一套知识网络。  
【范围边界】：
- 包含：高中数学、物理、化学、生物、语文、英语、信息与通用能力、学习与考试策略。
- 不包含：大学高等数学、大学物理、竞赛化学深层理论、科研训练体系、职业教育专项技能。
- 前置依赖：初中数学运算、基础科学常识、基本阅读表达、英语基础词汇。
【目标受众与用途】：高中理科生自学规划、家长/教师辅导、阶段复习、知识查漏补缺。  
【典型应用场景】：高一选科与基础搭建、高二专题深化、高三一轮/二轮/考前复盘。

## 一、顶层知识：八大主干

> 查看顶层思维导图：[knowledge_top.html](knowledge_top.html)

### 1. 数学
数学是理科学习的底层语言。高中数学不仅服务于高考数学本身，也为物理建模、化学计算、生物统计和信息处理提供工具。核心包括函数与映射、三角函数、数列、不等式、导数、解析几何、立体几何、概率统计。

### 2. 物理
物理训练学生用模型解释自然现象。主线从受力分析进入牛顿定律，再扩展到运动学、功和能、动量、电场、电路和电磁感应。物理学习的关键不是背公式，而是明确研究对象、过程、约束条件和守恒关系。

### 3. 化学
化学连接微观粒子、物质结构和宏观反应。高中化学主线包括物质的量、离子反应、氧化还原、化学平衡、电化学、有机结构、实验操作、元素周期律。化学学习要同时兼顾概念、方程式、计算和实验现象。

### 4. 生物
生物强调结构与功能、稳态与调节、遗传与进化、生态与实验。高中生物核心包括细胞结构、物质运输、酶与代谢、遗传规律、DNA 表达、生命活动调节、生态系统和实验设计。

### 5. 语文
语文是理科生的阅读、表达和论证基础。理科生常见短板不是“文学性不足”，而是审题、信息整合、论证组织和作文立意不稳。现代文阅读、文言文、古诗鉴赏、作文立意、论证结构、语言表达、材料整合、审题共同构成语文主线。

### 6. 英语
英语在高中阶段主要承担信息获取与表达能力训练。词汇语法、长难句、阅读理解、完形填空、七选五、英语写作、听说能力、翻译表达构成主干。对理科生而言，阅读理解和长难句分析通常是提分核心。

### 7. 信息与通用能力
理科学习离不开数据、图表、工具和模型。算法思维、数据处理、图表解读、计算工具、模型意识、信息检索、错题系统和时间管理，是连接各科的通用底层能力。

### 8. 学习与考试策略
知识体系最终要落到学习过程。目标拆解、预习听课、复盘总结、刷题策略、考试节奏、实验安全、变量控制和心理调节，决定知识能否稳定转化为成绩和能力。

## 二、中间层知识：三维矩阵

> 查看动态矩阵：[knowledge_middle.html](knowledge_middle.html)

### 2.1 维度定义
- 维度①：知识模块。取值：数学、物理、化学、生物、语文、英语、通用能力、学习策略。
- 维度②：学习场景。取值：课堂学习、作业训练、实验探究、综合应用、考试输出。
- 维度③：难度层级。取值：入门、进阶、高级。

### 2.2 矩阵解读
- 数学 × 综合应用：函数、导数、解析几何和概率统计，是物理建模、数据分析和综合题的工具基础。
- 物理 × 综合应用：受力分析、牛顿定律、能量和电磁，是理科模型化思维的典型训练场。
- 化学 × 实验探究：实验操作、离子检验、反应现象和变量控制，是化学从记忆走向理解的关键。
- 生物 × 实验探究：遗传、代谢和实验设计结合紧密，要求能读懂图表并判断变量。
- 语文/英语 × 考试输出：审题、材料整合、长难句、阅读定位和写作，是理科生非理科科目的稳定得分点。
- 通用能力 × 全场景：图表解读、模型意识、错题系统、时间管理贯穿所有学科。

### 3.1 核心节点群
- 数学：函数与映射、三角函数、数列、不等式、导数、解析几何、立体几何、概率统计。
- 物理：受力分析、牛顿定律、运动学、功和能、动量、电场、电路、电磁感应。
- 化学：物质的量、离子反应、氧化还原、化学平衡、电化学、有机结构、化学实验操作、元素周期律。
- 生物：细胞结构、物质运输、酶与代谢、遗传规律、DNA 表达、生命活动调节、生态系统、生物实验设计。
- 语文：现代文阅读、文言文、古诗鉴赏、作文立意、论证结构、语言表达、材料整合、审题。
- 英语：词汇语法、长难句、阅读理解、完形填空、七选五、英语写作、听说能力、翻译表达。
- 信息与通用能力：算法思维、数据处理、图表解读、计算工具、模型意识、信息检索、错题系统、时间管理。
- 学习与考试策略：目标拆解、预习听课、复盘总结、刷题策略、考试节奏、实验安全、变量控制、心理调节。

### 3.2 关键依赖路径
- 数学底线：函数与映射 → 不等式 → 导数 → 模型意识。
- 物理底线：受力分析 → 牛顿定律 → 运动学/功和能 → 模型意识。
- 化学底线：物质的量 → 离子反应 → 氧化还原 → 化学平衡 → 电化学。
- 生物底线：细胞结构 → 物质运输 → 酶与代谢 → 生命活动调节；遗传规律 → DNA 表达。
- 语言底线：审题 → 作文立意 → 论证结构 → 材料整合；词汇语法 → 长难句 → 阅读理解。
- 学习底线：目标拆解 → 时间管理 → 考试节奏；预习听课 → 复盘总结 → 刷题策略。

### 3.3 使用建议
高一应优先补齐函数、受力分析、物质的量、细胞结构、词汇语法和审题能力。高二应进入导数、电磁、化学平衡、遗传、长难句和实验设计。高三应围绕模型意识、图表解读、错题系统、刷题策略和考试节奏进行综合复盘。
