# 金融知识体系

> 金融是研究资金在时间、风险、机构和市场之间配置的知识领域，连接个人储蓄、企业融资、资产定价、风险管理、金融机构、监管制度与宏观经济。本文按 KSB_V3.3 构建三层体系：顶层用三级思维导图梳理主干，中间层用三维动态矩阵展示交叉结构，底层用 64 个核心知识点构建分组聚类知识图谱。本文仅用于学习与知识组织，不构成投资、税务、法律或理财建议。

## 一、顶层知识：领域主干（思维导图式展开）
> 查看对应图表：[knowledge_top.html](knowledge_top.html)  
> 读图方式：根节点为“金融”，左右展开 8 个一级主干；每个主干下有二级子主题和三级知识点，默认展开到三级。顶层回答“金融有哪些大块知识”，帮助先建立地图，再进入矩阵和图谱。

### 1.1 金融体系与市场
- 定义：金融体系是资金供给者、资金需求者、金融中介、市场基础设施和规则共同组成的资源配置网络。
- 核心要点：资金从储蓄端流向投资端；市场分为货币市场、资本市场、外汇市场、衍生品市场；价格、流动性和信息披露决定市场效率。
- 可验证实例：一家公司发行债券融资，投资者购买债券，交易所、承销商、清算机构和监管规则共同完成资金转移。
- 关键子主题：金融中介、一级/二级市场、交易机制、清算结算、信息效率、市场流动性。

### 1.2 货币银行与中央银行
- 定义：货币银行体系研究货币创造、商业银行资产负债、支付清算、中央银行政策与金融稳定。
- 核心要点：银行通过存贷款转换期限与风险；中央银行通过政策利率、公开市场操作、准备金和流动性工具影响金融条件；支付系统是金融活动的底层管道。
- 可验证实例：央行加息通常会提高短端利率，进而影响贷款利率、债券价格和资产估值折现率。
- 关键子主题：货币供给、存款准备金、商业银行、央行政策、支付系统、金融稳定。

### 1.3 公司金融
- 定义：公司金融研究企业如何投资、融资、分红和管理资本结构，以提升企业价值。
- 核心要点：投资决策看净现值和现金流；融资决策权衡债务、股权和资本成本；营运资本管理决定日常流动性。
- 可验证实例：若一个项目预期现金流折现后的净现值为正，且风险估计合理，则理论上可增加企业价值。
- 关键子主题：资本预算、现金流估值、资本结构、股利政策、并购重组、营运资本。

### 1.4 投资与资产定价
- 定义：投资与资产定价研究资产价格如何由预期收益、风险、现金流和市场供需共同决定。
- 核心要点：收益与风险通常存在权衡；分散化可降低非系统性风险；估值模型依赖现金流、折现率和增长假设。
- 可验证实例：同一现金流在更高折现率下对应更低现值，债券和股票估值都会受到影响。
- 关键子主题：风险收益、投资组合、CAPM、因子模型、折现现金流、有效市场。

### 1.5 金融工具与资产类别
- 定义：金融工具是承载现金流、所有权、债权、风险转移或价格敞口的合约。
- 核心要点：股票代表权益，债券代表债权，基金实现集合投资，衍生品用于套期保值或风险转移，另类资产提供不同风险来源。
- 可验证实例：一只宽基 ETF 持有多只股票，相比单一股票通常能降低公司特有风险，但仍承担市场风险。
- 关键子主题：股票、债券、基金、ETF、期货、期权、外汇、房地产与另类资产。

### 1.6 风险管理
- 定义：风险管理识别、度量、监控和缓释金融活动中的不确定性损失。
- 核心要点：市场风险来自价格波动，信用风险来自违约，流动性风险来自无法及时成交或融资，操作风险来自流程、系统或人为失误。
- 可验证实例：债券久期越高，在利率上升时价格通常越敏感；这可以用久期近似公式做压力测试。
- 关键子主题：风险识别、VaR、压力测试、久期、信用评级、对冲、流动性管理。

### 1.7 金融科技与数据
- 定义：金融科技用数据、算法、网络基础设施和软件系统提升金融服务效率与覆盖面。
- 核心要点：支付、信贷、投顾、风控、区块链和监管科技都依赖数据治理与模型风险控制；技术效率必须和安全、合规、隐私平衡。
- 可验证实例：信用评分模型可用还款历史、收入稳定性等变量估计违约概率，但需要防止偏见、过拟合和数据泄露。
- 关键子主题：支付科技、数字银行、量化投资、智能投顾、区块链、数据治理、模型风险。

### 1.8 监管伦理与个人财务
- 定义：监管伦理与个人财务关注金融行为的边界、投资者保护、信息披露、利益冲突和个体财务安全。
- 核心要点：监管维护市场公平和系统稳定；伦理约束代理问题和利益冲突；个人财务强调预算、保险、应急金、资产配置和长期规划。
- 可验证实例：SEC Investor.gov 强调资产配置应结合风险承受能力和时间期限，分散化有助于降低单一投资风险。
- 关键子主题：投资者保护、信息披露、反洗钱、适当性、预算、保险、税务基础、退休规划。

## 二、中间层知识：多维矩阵（知识矩阵式展开）
> 查看对应图表：[knowledge_middle.html](knowledge_middle.html)

### 2.1 维度定义
- 维度①：知识模块。取值包括市场体系、银行货币、公司金融、投资定价、工具资产、风险管理、金融科技、监管个人。
- 维度②：应用场景。取值包括个人理财、企业决策、市场交易、机构管理、监管合规。
- 维度③：难度层级。取值包括入门、进阶、高级。

### 2.2 矩阵解读
- 重点交叉：投资定价 × 个人理财包含风险收益、分散化、资产配置和长期投资纪律，是非专业学习者最应先掌握的交叉区域。
- 重点交叉：公司金融 × 企业决策包含净现值、资本成本、资本结构和现金流管理，是理解企业价值创造的核心路径。
- 重点交叉：风险管理 × 机构管理包含信用风险、市场风险、流动性风险、压力测试和内控，是金融机构稳健经营的基础。
- 重点交叉：金融科技 × 监管合规包含数据治理、模型风险、网络安全和隐私保护，是现代金融服务不可绕开的约束。
- 盲区标注：部分高级主题如复杂衍生品定价、银行账簿利率风险、监管资本计量，需要更专门的数学、会计或法规材料补全。

## 三、最底层知识：知识网络（图谱式展开）
> 查看对应图表：[knowledge_bottom.html](knowledge_bottom.html)  
> 结构化数据：[knowledge_graph.json](knowledge_graph.json) / [knowledge_graph.csv](knowledge_graph.csv)

### 3.1 核心节点群（按主干分类）
- 金融体系与市场：资金盈余/短缺、金融中介、一级市场、二级市场、价格发现、流动性、清算结算、市场效率。
- 货币银行与中央银行：货币职能、存款创造、商业银行、资产负债管理、央行政策利率、公开市场操作、支付系统、金融稳定。
- 公司金融：财务报表、自由现金流、净现值、内部收益率、加权平均资本成本、资本结构、股利政策、并购估值。
- 投资与资产定价：风险收益权衡、投资组合、分散化、系统性风险、CAPM、因子模型、有效市场假说、行为金融。
- 金融工具与资产类别：股票、债券、久期、收益率曲线、基金、ETF、期货、期权。
- 风险管理：市场风险、信用风险、流动性风险、操作风险、VaR、压力测试、对冲、风险限额。
- 金融科技与数据：电子支付、数字银行、信用评分、量化交易、智能投顾、区块链、数据治理、模型风险。
- 监管伦理与个人财务：投资者保护、信息披露、适当性原则、反洗钱、预算管理、应急金、保险、退休规划。

### 3.2 关联类型与网络特征
- 高频关系：依赖与包含关系占主导，说明金融知识学习需要先理解基础现金流、风险收益、市场机制，再进入工具、模型和策略。
- 关键枢纽节点：风险收益权衡、分散化、投资组合、净现值、加权平均资本成本、商业银行、央行政策利率、信息披露、数据治理。
- 图谱结构：金融体系与市场提供制度背景；货币银行影响利率和流动性；公司金融连接企业现金流和资本成本；投资定价连接风险、收益和资产价格；风险管理贯穿所有模块。

### 3.3 推荐学习路径
- 速成路线（约 12 小时）：金融体系与市场 → 金融中介 → 股票/债券/基金/ETF → 风险收益权衡 → 分散化 → 资产配置 → 投资者保护。前置依赖：基本数学、复利、现值概念。
- 系统学习路线（约 40 小时）：货币职能 → 商业银行 → 央行政策利率 → 市场利率 → 财务报表 → 自由现金流 → 净现值 → WACC → 投资组合 → CAPM → 风险管理 → 监管伦理。前置依赖：会计基础、概率统计、宏观经济入门。
- 工程/数据路线（约 30 小时）：数据治理 → 信用评分 → 模型风险 → 量化交易 → 风险限额 → 压力测试 → 监管合规。前置依赖：Python/SQL、统计建模、隐私与安全基础。
