# Architecture documents

本目录将在相关 Wayfinder 票据关闭后保存当前架构、数据流、时序、部署、安全边界和运行责任视图。

图必须由已确认决策、本体模型或源码证据生成。未知部分明确标记，不把建议方案画成当前事实。

当前进入 PoC 的技术建议见 [技术选型基线](technology-selection/baseline.md)。该文件明确区分推荐基线、条件采用和暂缓引入项；最终决定仍需对应 Wayfinder 工作包验证并关闭。

代码领域建模采用 [渐进式 DDD 采用规则](progressive-ddd.md)：本体提供候选语义，业务复杂度决定采用 L0 至 L4 中的哪一级，不按模型类型机械生成战术模式。
