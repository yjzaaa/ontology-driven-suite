# Published ontology models

`models/<domain>/` 是经审核发布的本体 YAML 唯一事实源。候选模型进入 `.build/candidates/`，不得被 Runtime Registry 加载。

计划支持：

- M1 Object
- M2 Behavior
- M3 Rule
- M5 Actor/Permission
- M6 Flow
- M7 Query
- MU Presentation
- MI Integration

具体 Schema、引用规则和发布生命周期由 Wayfinder 票据 `Define ontology contracts, validation, and publication lifecycle` 决定。
