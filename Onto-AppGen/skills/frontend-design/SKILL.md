# 前端设计规范（frontend-design）

你是本体工作台的「界面设计规范」。当大模型要把本体模型转成 UI Schema（页面/表单/表格/详情的组织）时，**必须先读本规范**，让产出的界面专业、克制、信息层级清晰。你的产出不是代码，而是**设计决策依据**：组件选型、布局、配色、间距、视觉层级。

## 设计哲学

企业级应用的美观来自**克制与秩序**，不是花哨。三原则：
1. **信息层级优先**——标题/正文/辅助文字三级分明，一眼看出主次。
2. **留白即呼吸**——宁可多空，不要挤。间距用 8px 基准网格。
3. **颜色仅表意**——颜色只用来表达状态（成功/警告/错误）与强调（主操作），不作装饰。

## 一、配色系统（浅色专业风为默认）

| 角色 | 色值 | 用途 |
|---|---|---|
| 主色 primary | `#4F46E5`（靛蓝，低饱和） | 主按钮、链接、选中态 |
| 主色 hover | `#4338CA` | 主按钮悬停 |
| 页面背景 | `#F5F6FA` | 最底层 |
| 卡片/内容背景 | `#FFFFFF` | 表单卡、表格卡 |
| 主标题文字 | `#0F172A` | 页面/卡片标题 |
| 正文文字 | `#334155` | 正文、表单值 |
| 辅助文字 | `#94A3B8` | 占位、说明、次要信息 |
| 边框/分割线 | `#E2E8F0` | 卡片描边、表格线 |
| 成功 success | `#10B981` | 正常/已完成状态 |
| 处理中 processing | `#3B82F6` | 进行中状态 |
| 警告 warning | `#F59E0B` | 待处理/待派单状态 |
| 错误 error | `#EF4444` | 失败/异常/停用状态 |
| 默认 default | `#64748B` | 中性/已关闭状态 |

**硬性规则**：不允许大面积高饱和色块做背景；不允许深色侧边栏配高亮蓝；不允许彩虹式多用强调色。主色只出现在主按钮与选中态。

## 二、字号阶梯

| 层级 | 大小 | 字重 | 用途 |
|---|---|---|---|
| 页面标题 | 20px | 600 | 页面名 |
| 卡片标题 | 15px | 600 | 表单卡/表格卡标题 |
| 正文 | 14px | 400 | 表单值、表格内容 |
| 辅助 | 12px | 400 | 说明、占位、次要 |

## 三、间距与圆角阴影

- 间距用 **8px 基准**：4 / 8 / 12 / 16 / 24 / 32。卡片内边距 20px，卡片间距 16px，表单字段间距 16px。
- 圆角：卡片 10px，输入框/按钮 8px，标签 Tag 6px。
- 阴影：**轻**——卡片用 `0 1px 2px rgba(15,23,42,.04), 0 4px 12px rgba(15,23,42,.04)`；不要重投影、不要发光描边。

## 四、组件使用规范（场景 → 组件）

| 业务场景 | 用什么 | 不要用什么 |
|---|---|---|
| 数据录入 | 表单（标签在上、垂直布局、必填星号） | 一堆裸输入框横排 |
| 数据列表 | 表格（紧凑、斑马纹可选、状态用 Tag） | 卡片堆叠当列表 |
| 状态字段 | Tag（用上面的语义色映射） | 纯文本写状态 |
| 关键指标 | 统计卡 Statistic | 大段文字描述数字 |
| 详情查看 | 描述列表 Descriptions | 再塞一张表单 |
| 行内操作 | link 型小按钮（派单/完成/关闭） | 一排实心大按钮 |
| 危险操作 | 需 confirm 确认框 | 一键直接执行 |

## 五、布局模式

- **导航**：左侧窄栏（200px）深色 `#0F172A`，菜单文字浅灰，选中项主色。
- **内容区**：浅色背景 + 白色卡片承载每个 Block。
- **表单**：单列垂直、标签在上；字段多时可用两列网格。
- **表格**：上方放行筛选器（下拉），行尾放操作按钮。

## 六、生成 UI Schema 时的强制约束

大模型产出 UI Schema 时：
1. 状态字段一律 `render: "tag"`，且 `tagMap` 用本规范语义色。
2. 表单字段必填项标 `required: true`（渲染出星号 + 校验）。
3. 引用字段一律 `control: "select"` + `refTable`（下拉，不让人手输编号）。
4. 枚举字段一律 `control: "select"` 或 `radio`（选项 ≤3 用 radio，否则 select）。
5. 每个页面 block 不宜超过 3 个；表单字段超过 6 个就考虑分步或分组。
6. 操作按钮配 `visibleWhen`（按状态显隐），不要全堆出来。

## 七、禁忌（违反即不美观）

- ❌ 大面积高饱和色块背景、彩虹配色
- ❌ 默认 antd 蓝 `#1677FF` 大面积使用、深色侧栏配亮蓝
- ❌ 重阴影、发光描边、花哨渐变按钮
- ❌ 状态用纯文本而非 Tag
- ❌ 所有操作按钮永远显示（不分状态显隐）
- ❌ 字段挤一行、无留白
