本体模型编辑器前端页面与组件设计

一、文档定位

本文件基于 [本体模型维护需求V2.txt](d:/myapp1/meta/Requirement/本体模型维护需求V2.txt)，用于指导前端 React + TypeScript 开发。

本文件关注：
1. 页面结构
2. 组件拆分
3. 状态组织
4. 交互规则
5. 与后端 API 的协作边界


二、前端总体目标

前端的核心职责不是“管理数据库记录”，而是提供一个面向 YAML 本体模型的编辑器界面。

前端必须支持：
1. 打开一组 YAML 模型文件
2. 将其组织成统一的工作区视图
3. 以树状结构浏览对象、行为、规则、事件、场景
4. 对定义节点进行编辑
5. 对引用节点进行跳转或局部配置
6. 发起校验
7. 保存为 YAML 文件


三、页面结构

3.1 主页面

建议采用三栏布局：
1. 左栏：模型树与搜索区
2. 中栏：主编辑区
3. 右栏：详情/引用/校验结果区

顶部为工具栏，底部可选状态栏。


3.2 页面模块划分

建议页面至少包含以下模块：
1. `AppShell`
2. `TopToolbar`
3. `ModelTreePanel`
4. `EditorWorkspace`
5. `InspectorPanel`
6. `StatusBar`
7. `ImportExportDialog`
8. `ValidationPanel`


四、页面功能分解

4.1 顶部工具栏

工具栏至少包括：
1. 新建工作区
2. 导入模型
3. 保存全部
4. 另存导出
5. 运行校验
6. 搜索
7. 展开/折叠树
8. 切换视图

状态信息至少包括：
1. 当前 domain
2. 是否有未保存修改
3. 最近一次校验状态


4.2 左侧模型树

树根下建议固定五个一级节点：
1. 对象模型
2. 行为模型总览
3. 规则模型
4. 事件模型
5. 场景模型

对象模型树结构建议：
1. 对象
2. 属性
3. 关系
4. 约束
5. 行为

行为模型总览建议支持两种模式：
1. 按对象分组
2. 扁平列表

事件模型树结构建议：
1. 事件定义
2. 触发行为
3. 触发对象
4. 订阅行为列表

场景模型树结构建议：
1. UseCases
2. BusinessProcesses
3. 步骤节点
4. 引用行为/事件


4.3 中间编辑区

编辑区采用 Tab 模式：
1. 一个节点一个编辑标签页
2. 支持同时打开多个节点
3. 支持未保存状态标记

编辑区内按节点类型加载不同编辑器：
1. `EntityEditor`
2. `BehaviorEditor`
3. `RuleEditor`
4. `EventEditor`
5. `UseCaseEditor`
6. `BusinessProcessEditor`
7. `ReadOnlyReferenceView`


4.4 右侧详情区

右栏承担辅助信息，不承担主要编辑职责。

建议内容包括：
1. 当前选中节点的元信息
2. 被引用关系
3. 引用来源
4. 校验错误列表
5. 快速跳转入口


五、核心组件设计

5.1 应用骨架组件

`AppShell`
职责：
1. 组织全局布局
2. 注入全局状态
3. 管理工作区生命周期

`TopToolbar`
职责：
1. 提供主操作入口
2. 反映文件与校验状态

`StatusBar`
职责：
1. 显示当前工作区路径
2. 显示保存状态
3. 显示当前选中节点类型与 ID


5.2 模型树组件

`ModelTreePanel`
职责：
1. 渲染左侧树
2. 支持搜索过滤
3. 支持展开/折叠
4. 支持选中与定位

`TreeSearchBox`
职责：
1. 按名称、ID、别名、描述关键字搜索

`TreeNodeRenderer`
职责：
1. 为不同节点类型显示不同图标和样式
2. 区分定义节点和引用节点

节点样式规则：
1. 定义节点使用实心图标
2. 引用节点使用线框或链接图标
3. 有错误的节点显示错误标识
4. 有未保存修改的节点显示脏状态标识


5.3 编辑器组件

`EntityEditor`
至少包含：
1. 基本信息表单
2. 属性表格
3. 关系表格
4. 约束表格
5. 关联行为只读列表

`BehaviorEditor`
至少包含：
1. 基本信息表单
2. 前置条件编辑器
3. 后置条件编辑器
4. 应用规则选择器
5. 说明/备注编辑区

`RuleEditor`
至少包含：
1. 规则基本信息
2. 输入参数编辑
3. 输出类型选择
4. 表达式编辑器
5. 复用来源展示

`EventEditor`
至少包含：
1. 事件基本信息
2. 生产者行为选择器
3. 生产者对象自动展示
4. 订阅行为多选器
5. payload 字段编辑器
6. triggerCondition 编辑器
7. 备注编辑区

`UseCaseEditor`
至少包含：
1. 基本信息
2. 前置条件与后置条件
3. 主流程步骤编辑器
4. 替代流程编辑器
5. 异常流程编辑器
6. 说明与备注编辑区

`BusinessProcessEditor`
至少包含：
1. 基本信息
2. 用例引用列表
3. orchestration 步骤编辑器
4. 说明与备注编辑区

`ReadOnlyReferenceView`
用于：
1. 场景里的行为引用
2. 事件里的 producer/subscriber 引用
3. 展示引用目标摘要
4. 提供“跳转到定义”按钮


5.4 通用表单子组件

建议抽取以下通用子组件：
1. `TextField`
2. `TextAreaField`
3. `EnumSelect`
4. `ReferenceSelect`
5. `MultiReferenceSelect`
6. `KeyValueTable`
7. `ExpressionEditor`
8. `CodeBlockEditor`
9. `ArrayEditor`
10. `StepListEditor`
11. `YamlPreviewPanel`


六、状态管理设计

6.1 状态分层

前端状态建议分为三层：
1. 服务端同步状态
2. 本地工作区编辑状态
3. 纯 UI 状态

服务端同步状态包括：
1. 当前模型文件内容
2. 校验结果
3. 文件路径

本地工作区编辑状态包括：
1. 统一模型仓库
2. 已打开标签页
3. 节点脏状态
4. 最近一次导入快照

纯 UI 状态包括：
1. 树展开状态
2. 搜索关键字
3. 当前选中节点
4. 面板尺寸


6.2 模型仓库结构建议

前端内存中建议维护一个统一工作区对象：
1. `objectModel`
2. `behaviorModel`
3. `ruleModel`
4. `eventModel`
5. `scenarioModel`
6. `fileMeta`
7. `validationState`
8. `dirtyState`
9. `extensions`

说明：
1. 这是编辑态工作结构，不是正式持久化格式。
2. 必须支持保留扩展字段。


七、关键交互规则

7.1 节点打开规则

1. 点击对象下的行为，打开 `BehaviorEditor`
2. 点击场景中的行为引用，打开 `ReadOnlyReferenceView`
3. 点击引用视图中的“跳转到定义”，切换到对应定义标签页
4. 点击事件中的 producer/subscriber 行为，默认先打开只读引用视图


7.2 编辑权限规则

1. 定义节点可编辑
2. 引用节点默认不可直接编辑定义
3. 场景步骤中允许编辑步骤级信息，如 `paramMapping`、描述、nextSteps
4. 不允许在场景步骤里修改被引用行为的核心定义


7.3 删除规则

前端发起删除前，必须先请求后端检查引用关系。

删除确认框至少展示：
1. 将删除的目标名称
2. 受影响引用数量
3. 受影响文件
4. 是否允许强制删除


7.4 保存规则

1. 保存全部时统一提交工作区改动
2. 若存在校验错误，可允许保存草稿，但应明确提示
3. 保存成功后更新脏状态
4. 保存失败后保留本地编辑内容


八、导入导出交互

8.1 导入

导入方式建议支持：
1. 选择目录
2. 逐个上传 YAML 文件

导入完成后前端应展示：
1. 成功导入文件列表
2. 缺失文件列表
3. 结构警告
4. 引用错误
5. 扩展字段保留提示


8.2 导出

导出前应允许用户：
1. 选择导出目录
2. 预览将输出的文件列表
3. 查看是否有未解决校验错误

导出成功后应显示：
1. 输出文件路径
2. 导出文件数
3. 警告信息


九、错误提示与可视反馈

前端必须清晰区分：
1. 结构错误
2. 引用错误
3. 文件读写错误
4. 校验警告
5. 未保存提示

错误展示方式建议：
1. 表单内联错误
2. 右栏错误列表
3. 树节点错误徽标
4. 顶部全局通知

十一、前后端协作边界

前端负责：
1. 可视化
2. 本地编辑态状态管理
3. 基础字段级校验
4. 用户交互与提示

后端负责：
1. 文件读写
2. YAML 解析与序列化
3. 跨文件模型校验
4. 删除影响分析
5. 扩展字段保留


十二、一期前端交付清单

一期建议最少交付：

2. 五类树节点导航
3. Entity 编辑器
4. Behavior 编辑器
5. Rule 编辑器
6. Event 编辑器
7. UseCase / BusinessProcess 编辑器
8. 导入弹窗
9. 导出弹窗
10. 校验结果面板
11. 文件状态提示
