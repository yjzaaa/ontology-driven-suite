## 工作包目标

定义 M7 Query 从语义请求到受治理执行和稳定结果投影的完整契约。工作包必须对查询分类、DPA 读取接口与 Database MCP 的数据源选择、当前用户的行级和组织级范围、字段敏感性、资源限制、结果投影、审计与威胁处置形成可重复验证的规则。

本工作包只允许发布后 M7 与 MI 显式声明的查询能力，不允许模型提交任意 SQL、URL、HTTP Method、Header、表名或绕过数据范围的参数；Database MCP 始终只读。

## 必需 Task

### [ ] T06.1 定义 M7 查询分类与准入契约

**达成目标**

建立 M7 Query 的分类体系和字段要求，使平台能在执行前确定查询目的、结果形态、风险等级、允许的数据源和必要治理控制。

**输入**

- 工作包 03 的 M7 Query Schema、稳定 ID、版本与发布状态。
- 工作包 04 的 `IdentityContext` 和授权责任矩阵。
- MasterData 候选查询与典型用户问题。

**执行步骤**

1. 定义按结果形态划分的 `OBJECT_LOOKUP`、`COLLECTION_SEARCH`、`RELATION_TRAVERSAL`、`AGGREGATION` 和 `EXPORT`。
2. 定义按范围与风险划分的个人、组织、跨组织、敏感字段、聚合和大结果集等级。
3. 为每类查询规定必需字段、允许过滤器、排序、分页、聚合、关系、数据源候选和禁止能力。
4. 明确 M7 只能引用已发布 M1 Object、关系、字段、MI 和策略稳定 ID。
5. 生成合法查询、未发布引用、任意字段、任意关系、任意 SQL 和越权范围负向样例。

**产出物**

- `docs/contracts/query/m7-query-classification-and-admission.md`
- `models/examples/query/m7-query-classification-examples.yaml`
- `tests/spec/query/m7-admission-cases.yaml`

**验证方式**

- 每个代表性查询恰好具有一个主要结果分类和明确风险等级。
- Schema 或检查表可拒绝未发布引用、自由 SQL、自由表名和未声明关系。
- 每个分类均能推导出后续数据源、范围、限制和投影所需控制。

**前置 Task**

- 工作包 03
- 工作包 04

### [ ] T06.2 定义 DPA 读取接口与 Database MCP 的选择规则

**达成目标**

为每个 M7 Query 确定首选数据源和回退边界，在保持 DPA 最终授权的同时，避免调用存在混合副作用的读取端点。

**输入**

- T06.1 的查询分类。
- 工作包 05 的 MI、副作用分类与执行准入矩阵。
- DPA 读取端点、授权过滤器、业务层范围逻辑和 Database MCP capability 证据。

**执行步骤**

1. 比较 DPA 读取接口与 Database MCP 在业务语义、当前用户范围、字段投影、实时性、副作用和审计上的能力。
2. 定义必须选择 DPA、优先选择 Database MCP、允许二选一和一律拒绝的判定表。
3. 对无法证明纯读的 DPA Action 按 `MIXED/HIGH` 处理，不得作为自动查询数据源。
4. 定义 Database MCP 仅能使用预先批准的语义 capability、view 或参数化模板，禁止任意 SQL。
5. 定义数据源不可用时的回退规则；回退不得降低授权、范围或字段控制。
6. 为 MasterData 对象详情、列表搜索、关系查询和聚合各做一次数据源裁决。
7. 规定 Database MCP 通道“禁止任意 SQL”的强制执行机制：提交前经 AST 级解析校验（sqlglot 为首选候选）证明语句为单一只读查询且表、列、函数均落在批准 capability 闭包内；无法静态证明的语句一律拒绝。

**产出物**

- `docs/contracts/query/query-data-source-selection.md`
- `docs/contracts/query/masterdata-data-source-decisions.md`

**验证方式**

- 每个代表性 M7 均有唯一首选数据源、选择证据和禁止回退条件。
- 任一 `MIXED/HIGH` DPA 端点不会因名称或 HTTP Method 看似只读而被自动选用。
- Database MCP 样例只引用批准 capability，不包含 DDL、DML 或自由 SQL。
- 自由 SQL、多语句、写关键字与注释绕过样例在 AST 校验处被确定性拒绝。

**前置 Task**

- T06.1

### [ ] T06.3 定义行级与组织级数据范围

**达成目标**

把当前用户、租户、组织和业务归属约束转换为不可由模型覆盖的数据范围谓词，并明确 DPA 与 Database MCP 各自的强制执行点。

**输入**

- 工作包 04 的 `IdentityContext`、责任矩阵和失败语义。
- T06.2 的数据源选择。
- DPA 当前组织树、用户归属、角色过滤和业务对象所有权证据。

**执行步骤**

1. 定义租户、组织、子组织、本人、被授权对象和公共对象等范围原语。
2. 记录每个范围原语的事实来源、继承规则、交集/并集规则和拒绝默认值。
3. 定义 DPA 数据源由现有授权过滤器与业务层最终裁决；平台不得缓存或扩大其结果。
4. 定义 Database MCP 查询必须注入的服务端范围参数或批准谓词，禁止由语义输入覆盖。
5. 规定跨组织查询、管理员视图、缺少组织上下文和组织结构变化时的处理。
6. 生成同组织、子组织、跨组织、无归属、租户不匹配和伪造范围用例。

**产出物**

- `docs/contracts/query/query-row-and-organization-scope.md`
- `tests/spec/query/row-organization-scope-cases.yaml`

**验证方式**

- 每个用例均明确身份上下文、可见记录集合、拒绝记录集合和执行责任方。
- 扩大 `organization_scope`、替换 `dpa_user_id` 或移除租户谓词的输入在执行前失败。
- 缺失或冲突的范围事实采用拒绝默认值，不返回无范围数据。

**前置 Task**

- T06.2

### [ ] T06.4 定义字段敏感性与列级投影策略

**达成目标**

为 M1 字段和 M7 结果建立敏感性分级、用途限制、脱敏和禁止投影规则，确保有行权限不等于有全部字段权限。

**输入**

- 工作包 03 的 M1 Object 与字段元数据。
- T06.3 的数据范围。
- DPA DTO、页面展示、导出和日志中的敏感字段证据。

**执行步骤**

1. 定义公开、内部、敏感、受限和凭据类字段等级及判定标准。
2. 为每个等级规定查询、过滤、排序、聚合、展示、导出、日志和模型可见性。
3. 定义字段策略与 M5 Actor/Permission、用途和 M7 Query 类型的组合规则。
4. 定义遮罩、截断、哈希、枚举映射和完全删除等投影动作。
5. 明确密码、Cookie、Token、密钥和安全答案等凭据类字段永不进入查询结果。
6. 为同一行在不同角色、用途和结果形态下生成字段投影样例。

**产出物**

- `docs/contracts/query/field-sensitivity-and-projection-policy.md`
- `models/examples/query/masterdata-field-policy.yaml`
- `tests/spec/query/field-sensitivity-cases.yaml`

**验证方式**

- 每个被 M7 引用的字段均有敏感级别和允许动作，不允许未分类字段默认暴露。
- 负向用例证明通过过滤、排序、聚合、错误详情或日志不能旁路读取受限字段。
- 凭据类字段在所有投影和审计样例中均不存在真实值。

**前置 Task**

- T06.3

### [ ] T06.5 定义查询资源限制与执行保护

**达成目标**

限制查询的时间、行数、分页、关系深度、聚合复杂度、响应体和导出规模，防止资源耗尽、范围探测和不受控数据外流。

**输入**

- T06.1 的查询分类与风险等级。
- T06.2 的数据源能力。
- T06.3 和 T06.4 的范围与字段策略。
- DPA 与 Database MCP 的性能基线。

**执行步骤**

1. 为各查询分类定义默认和最大 `page_size`、总行数、执行时间、响应字节、关系深度和聚合基数。
2. 定义允许的分页模式、稳定排序、游标生命周期和重复请求行为。
3. 定义高成本过滤、模糊搜索、跨关系遍历、全量计数和大规模聚合的准入规则。
4. 定义取消传播、并发限制、速率限制、熔断和资源预算耗尽错误。
5. 单独定义 `EXPORT` 的准入、异步化、审批、文件保留和下载审计；未完成决策前默认禁止。
6. 生成边界值、超限、深层关系、慢查询、并发突发和导出场景。

**产出物**

- `docs/contracts/query/query-resource-limits.md`
- `tests/spec/query/query-resource-limit-cases.yaml`

**验证方式**

- 每个分类的最坏资源消耗可由限制表计算。
- 边界值用例通过，超出任一硬限制的用例在稳定位置失败并返回稳定错误码。
- 限制失败不得回退为无分页、无范围或低治理的数据源调用。

**前置 Task**

- T06.4

### [ ] T06.6 定义稳定结果投影与查询审计

**达成目标**

把不同数据源结果转换为稳定对象或集合投影，并记录足以复核查询授权、范围、字段、资源消耗和结果版本的审计链。

**输入**

- T06.2 至 T06.5 的数据源、范围、字段和限制规则。
- 工作包 05 的 MI 响应与错误标准化契约。
- M1 Object、关系和 MU Presentation 的候选字段。

**执行步骤**

1. 定义对象、集合、关系和聚合结果的统一 envelope。
2. 至少定义 `query_id`、`query_version`、`object_type`、`items`、`page_info`、`aggregations`、`warnings`、`source_as_of` 和 `correlation_id`。
3. 定义技术 DTO 到稳定对象字段的映射、空值、枚举、时间、标识和关系链接规则。
4. 定义查询审计字段：主体引用、组织范围、M7/MI 版本、数据源、策略版本、过滤器摘要、字段集合、资源消耗、结果计数、错误码和时间。
5. 定义日志脱敏、审计保留、访问控制和禁止记录原始敏感结果的规则。
6. 制作同一 M7 经允许的数据源返回等价投影的对照样例。

**产出物**

- `docs/contracts/query/query-result-and-audit-contract.md`
- `models/schema/query-runtime-result.schema.json`
- `tests/spec/query/query-result-audit-cases.yaml`

**验证方式**

- 所有代表性结果均通过 Schema 校验，并能被稳定解析为对象、集合、关系或聚合。
- 审计记录可回答“谁、何时、以何范围、用何版本、查询了什么、返回多少、为何允许或拒绝”。
- 审计样例不保存原始敏感结果、Cookie、Token、SQL 或内部堆栈。

**前置 Task**

- T06.5
- 工作包 05

### [ ] T06.7 建立查询威胁场景与端到端验收

**达成目标**

用可执行场景验证查询治理不会被提示注入、参数走私、范围篡改、字段推断、关系遍历、聚合旁路、资源耗尽或数据源回退绕过。

**输入**

- T06.1 至 T06.6 的全部契约和样例。
- MasterData 代表性对象、用户、组织和敏感字段测试数据定义。

**执行步骤**

1. 建立威胁清单，至少覆盖任意 SQL、自由字段、隐藏参数、范围覆盖、跨租户、未声明关系、敏感字段过滤推断、聚合小样本推断、分页爬取、超限查询和不安全回退。
2. 为每个威胁定义攻击输入、预期阻断层、稳定错误码和审计证据。
3. 制作成功对象查询、受范围限制的集合查询、允许聚合和被拒导出的端到端场景。
4. 验证同一用户重复执行得到治理语义一致的结果，不同用户按范围与字段策略得到预期差异。
5. 建立 M7、MI、身份上下文、数据源、策略、结果 Schema 和审计事件的追踪矩阵。

**产出物**

- `docs/security/governed-query-threat-model.md`
- `tests/spec/query/governed-query-end-to-end.yaml`
- `docs/contracts/query/governed-query-traceability-matrix.md`

**验证方式**

- 每个威胁至少有一个可重复执行的负向场景，且不以“模型应当遵守提示词”作为控制。
- 所有成功场景同时满足行级范围、字段策略、资源限制、结果 Schema 和审计要求。
- 所有拒绝场景在访问数据或扩大查询前失败；无法提前失败的场景必须证明数据源侧仍强制范围。
- 追踪矩阵不存在缺失的稳定 ID、策略、数据源、测试或审计链接。

**前置 Task**

- T06.6

## 工作包验收

- T06.1 至 T06.7 全部完成，所有产出路径可访问，场景可由非作者重复执行。
- 每个已发布 M7 均有明确分类、数据源、身份范围、组织范围、字段策略、资源限制、结果投影和审计规则。
- DPA 与 Database MCP 的选择有证据和确定性规则；无法证明纯读的 DPA 端点不进入自动查询。
- 模型不能提供任意 SQL、URL、Method、Header、表名、自由关系或安全范围参数。
- 行级、组织级和字段级控制采用拒绝默认值，数据源回退不得降低治理强度。
- 对象、集合、关系和聚合结果具有稳定 Schema，审计链可复核且不保存原始敏感结果。
- 威胁场景覆盖范围绕过、字段推断、资源耗尽和不安全回退，并具有明确阻断证据。
