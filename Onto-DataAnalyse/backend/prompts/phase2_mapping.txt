## 任务

为**以上每个实体**生成与数据库表的映射配置，输出**严格的 JSON**（不要 Markdown 代码块包裹，不要解释）：

```json
{{
  "entity_mappings": [
    {{
      "entity_id": "ENT-XXX-001",
      "entity_name": "实体名",
      "confidence": 0.95,
      "tables": [
        {{"table": "t_xxx", "alias": "x", "primary": true}}
      ],
      "field_mappings": [
        {{
          "ontology_field": "fieldName",
          "ontology_label": "中文名",
          "db_table": "t_xxx",
          "db_column": "field_name",
          "confidence": 1.0
        }}
      ],
      "default_filter": null
    }}
  ]
}}
```

## 紧凑输出规则（重要 — 节省 token）

1. **省略 null 字段**：`db_expression`、`note`、`value_mapping`、`join_on`、`default_filter` 如果值为 null，**不要写出来**
2. **只在字段需要表达式/转换时**才写 `db_expression`
3. **只在 confidence < 0.85** 时才写 `note` 解释原因
4. **只对枚举字段**才写 `value_mapping`（如 status 状态码 → 中文）
5. 不要重复字段名两次（如不要写 `"db_column": "user_id", "alias_for_user_id": ...`）

## 严格要求

1. 必须为**本批**列出的所有实体都生成映射（不能跳过）
2. 输出**纯 JSON**（不要 ```code block``` 包裹，不要解释文字）
3. confidence 范围 0.5-1.0；低于 0.5 的字段直接跳过
4. 所有 `db_table` / `db_column` 必须真实存在于 Schema 中
5. `tables[].primary: true` 必须有且仅有一个
