## 任务

判断用户意图最匹配哪个场景。只输出**严格的 JSON**（不要 Markdown 代码块，不要解释文字）：

```json
{{
  "scenario_id": "<SCN-... 之一，或 null 如果都不匹配>",
  "confidence": 0-100,
  "matched_keywords": ["命中的关键词1", "..."],
  "reasoning": "<一句话说明判断理由>",
  "alternatives": [
    {{"scenario_id": "<次选>", "confidence": 0-100}}
  ]
}}
```

判断规则：
- 命中触发词中任意一个 → 置信度 ≥ 80
- 语义相近但未直接命中 → 置信度 60-79
- 模糊不清 → 置信度 30-59
- 完全不相关 → scenario_id 为 null
